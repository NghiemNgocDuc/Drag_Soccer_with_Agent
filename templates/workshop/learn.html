How the checks work

Each check runs your exact editor code headlessly for up to 30 kicks per match against the lesson's opponent using the real physics and goals. At the kick limit, the higher score wins; equal scores are a draw. Most lessons need 3 wins out of 5. Search opponents like Expectimax can take longer; the page shows check status. Completed lessons stay completed — re-runs never undo progress.

Where to take your model next

Playground — test your code interactively (human vs code, or code vs any built-in with auto-play). My Models — save your code, then Submit to Leaderboard in the capstone to rank it against the current built-ins and every other builder's models.

Agent Soccer — the tutorial milestones are computed on the server from real engine matches.
