How the checks work

Each check runs your exact editor code headlessly for a few full matches against the lesson's opponent (physics, goals, halves — the real engine). Most lessons need 3 wins out of 5. Heavy opponents like Minimax take a minute or two; the page shows live progress. Completed lessons stay completed — re-runs never undo progress.

Where to take your model next

Playground — test your code interactively (human vs code, or code vs any built-in with auto-play). My Models — save your code, then Submit to Leaderboard in the capstone to rank it against the other 7 built-ins and every other builder's models.

Agent Soccer — the tutorial milestones are computed on the server from real engine matches.
