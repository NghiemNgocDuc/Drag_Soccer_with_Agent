How to write your Soccer AI — code contract

Your file must define exactly one function: get_ai_move(state, is_player_a). It is called once per turn and must return a 3-tuple (player_idx, angle_degrees, power). Any code outside the function (constants, helpers) is fine.

Required signature
def get_ai_move(state, is_player_a):
    # ... your strategy ...
    return player_idx, angle_degrees, power
Return values
player_idx    → int    0 / 1 / 2
               (which of YOUR 3 players kicks)
angle_degrees → float  direction of kick
               0 = right →   90 = down ↓
               180 = left ←  270 = up ↑
power         → float  0 – 100  (kick strength)
State dict keys
state["ball"]        # {"x": float, "y": float}
state["players_a"]   # list of 3 {"x":…, "y":…}
state["players_b"]   # list of 3 {"x":…, "y":…}
state["field"]       # {"width": 1400, "height": 875}
state["score_a"]     # int
state["score_b"]     # int
state["kick_count"]  # int
state["period"]      # str
state["game_over"]   # bool
Field layout (1400 × 875)
 x=0  ←GOAL B←            →GOAL A→   x=1400
        (y 356–519)        (y 356–519)
 is_player_a=True  → YOU attack RIGHT (x=1400)
 is_player_a=False → YOU attack LEFT  (x=0)
 always read the field size from state —
 never hardcode these numbers!
